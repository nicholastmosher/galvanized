# scripts/ — Goodies

Small dev-ergonomics scripts proposed via the [Goodie process]
(../memory/GOODIES.md). Each script has a sibling `<name>.md` doc with the
justification, how-it-works explanation, and manual usage.

**All scripts here are read-only by default** against the repo: they
*report* (print drift, print what would run) but do not *mutate* source
or git state unless their proposal explicitly says so and Nick approved
that mutation. See the [charter](../memory/GOODIES.md) for the full rules.
